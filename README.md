# Knife Dozor [CS2] v3.0

Плагин для **knife-серверов** (35hp и knife-карты). Делает ножевые бои честными, динамичными и удобными.

## ✨ Основные возможности

1. **Авто 35 HP + 0 armor** — при спавне и после каждого урона здоровье автоматически восстанавливается до 35.
2. **Защита от удара в спину** — удар в спину полностью блокируется, жертва респавнится, атакующий получает сообщение.
3. **Anti-Chain** — после убийства игрок не может нанести следующий урон ножом в течение 2 секунд (настраивается).
4. **Spawn Protect** — защита сразу после спавна (работает до первой смерти).
5. **Показ дистанции** — после каждого убийства оба игрока видят точную дистанцию в метрах.

## Визуальные индикаторы
- Цвет игрока во время Spawn Protect
- Предупреждение в центре экрана при Anti-Chain

## Настройки (KnifeDozor.json)
- Включение/выключение плагина
- Работает только на 35hp-картах или на всех knife-картах
- Время Anti-Chain (1–5 сек)
- Время Spawn Protect (0.5–5 сек)
- Цветовые индикаторы (можно отключить)

## Команды (только для Root-админов)
- `css_kd_help` — справка по командам
- `css_kd_settings` — текущие настройки
- `css_kdt` — тестовое меню
- `css_kd_reload`, `css_kd_enabled`, `css_kd_protecttime`, `css_kd_antichaintime`
